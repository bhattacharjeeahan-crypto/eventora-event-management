# Eventora – Discover. Connect. Celebrate.

Eventora is a responsive event management website that helps users explore upcoming events and register for their favourite experiences.

## Features

- Responsive homepage design
- Upcoming event cards with images and details
- Search events by name or keyword
- Filter events by category
- Interactive event details popup
- Event registration form
- Form validation using JavaScript
- Registration confirmation message
- Save registrations using browser Local Storage
- Dark and light mode toggle
- Persistent theme preference

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Git and GitHub

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## Registration Storage

Registration information is stored in the visitor's browser using Local Storage. This project currently does not use a backend server or central database.
